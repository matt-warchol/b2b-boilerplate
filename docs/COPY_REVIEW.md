# B2B copy review

Use three passes with different jobs. They can be done in one session or assigned as separate reviewer roles when the user wants delegation.

1. **Marketing:** Pin down the segment, the trigger, the alternatives, and one differentiated result. Mark which evidence supports the result. Select the sections that answer the buyer’s questions in order.
2. **Sales:** Read it as the buyer. Say what happens after the CTA, who does the work, what the customer receives and keeps, and what can block the deal. Use the language of the buyer and daily user. Address security, integration, procurement, and pricing only when relevant.
3. **Copywriter:** Assemble the page. Lead with the job in specific language, pair each promise with evidence, and keep one action primary. Preserve already useful lines. Offer alternatives for the headline only if there is a real trade-off.

## Final voice pass

If the current Claude Code installation exposes the user’s **Unslop AI** skill (for example `unslop-ai` or an equivalent registered name), invoke that skill on the assembled draft. Use the installed skill rather than guessing which public repo it came from. Preserve sourced claims, numbers, caveats, product terms, and voice. Compare before and after and reject changes that weaken meaning or add claims.

If the skill is unavailable, flag it and edit manually: cut stock hooks, buzzwords, empty benefits, forced contrasts, and repeated sentence rhythms. Replace generic adjectives with a concrete action or artifact. Read aloud to catch stiff phrasing. If a competitor could use the same sentence untouched, find a fact to sharpen it or remove it. Mark missing evidence in the brief or audit rather than filling it in.

## Example checks

- “Unlock smarter bid decisions” → “Shortlist the tenders your team can bid on.”
- “Seamless collaboration” → “Keep the deadline and next action on each tender.”
- A conversion uplift, customer quote, or real customer logo needs a source and permission before publishing.
